Paste any LaTeX-rich Markdown. This tool replaces each math fragment with an image URL (Codecogs by default) so it renders correctly anywhere (Google Docs, OneNote, etc.) without relying on MathJax. It understands inline \( ... \), block $$ ... $$, escaped brackets \[ ... \], and ChatGPT’s square-bracket blocks.

Use any image-rendering endpoint (PNG is safest for Google Docs / OneNote).
